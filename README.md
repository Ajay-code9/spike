# spike

SPIKE Global Brokerage Website - High-Fidelity Modern Trading Platform.

## Features
- Ultra-responsive, pixel-accurate design
- Seamless transparent hero header with glassmorphism on scroll
- Live ticker and 500+ global market instruments
- Professional trading platforms, accounts, and educational resources
- Vercel static deployment ready (`vercel.json`)

## Pages
- `index.html` - Homepage
- `platforms.html` - Trading Platforms
- `accounts.html` - Account Types
- `markets.html` - Markets & Instruments
- `education.html` - Education & Analysis
